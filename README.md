# Local Hive-test

## How do I install these formulae?

`brew install local/hive-test/<formula>`

Or `brew tap local/hive-test` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "local/hive-test"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
